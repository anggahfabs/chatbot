1. Clone repository
git clone <REPO_URL>
cd gemini-chatbot


2. Install dependency
npm install


3. Konfigurasi API Key

Buat file `.env` di root project:

GEMINI_API_KEY=ISI_API_KEY
API_KEY diambil dari google AI Studio


4. Jalankan server
node server.js


5. Buka aplikasi
Buka browser:


http://localhost:3000
